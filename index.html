개요#

Zero to Snowflake 빠른 시작에 오신 것을 환영합니다! 이 가이드는 Snowflake AI Data Cloud의 주요 영역을 하나의 과정으로 살펴봅니다. 먼저 웨어하우징과 데이터 변환의 기초를 배우고 자동화된 데이터 파이프라인을 구축합니다. 이어서 Cortex Playground에서 LLM을 실험하며 텍스트 요약에 사용할 다양한 모델을 비교하고, AISQL Function으로 간단한 SQL 명령만으로 고객 리뷰의 감성을 즉시 분석하며, Cortex Search로 지능형 텍스트 검색을 수행하고, Cortex Analyst로 대화형 비즈니스 인텔리전스를 활용하는 방법을 살펴봅니다. 마지막으로 강력한 거버넌스 제어 기능으로 데이터를 보호하고 원활한 데이터 협업을 통해 분석을 강화하는 방법을 배웁니다.

가상의 푸드 트럭 기업인 Tasty Bytes의 샘플 데이터 세트에 이러한 개념을 적용하여 데이터 운영을 개선하고 간소화해 보겠습니다. 워크로드별 여러 시나리오를 통해 이 데이터 세트를 살펴보며 Snowflake가 기업에 제공하는 이점을 알아봅니다.

Tasty Bytes는 어떤 기업인가요?#

Tasty Bytes의 사명은 지역 공급업체의 신선한 재료 사용을 중시하며 독특하고 품질 높은 음식을 편리하고 합리적인 가격으로 제공하는 것입니다. 탄소 발자국이 전혀 없는 세계 최대의 푸드 트럭 네트워크로 성장하는 것을 비전으로 삼고 있습니다.

학습할 내용#

  • 시나리오 1: Snowflake 시작하기: Snowflake 웨어하우스, 캐싱, 복제 및 Time Travel의 기초.
  • 시나리오 2: 간단한 데이터 파이프라인: Dynamic Table을 사용하여 반정형 데이터를 수집하고 변환하는 방법.
  • 시나리오 3: Snowflake Cortex AI: Snowflake의 포괄적인 AI 기능을 실험, 확장 가능한 분석, AI 지원 개발 및 대화형 비즈니스 인텔리전스에 활용하는 방법.
  • 시나리오 4: Horizon을 통한 거버넌스: 역할, 분류, 마스킹 및 로우 액세스 정책으로 데이터를 보호하는 방법.
  • 시나리오 5: 앱 & 협업: Snowflake Marketplace를 활용하여 타사 데이터 세트로 내부 데이터를 보강하는 방법.

구현할 내용#

  • Snowflake 핵심 플랫폼에 대한 포괄적인 이해.
  • 설정이 완료된 가상 웨어하우스.
  • Dynamic Table을 사용하는 자동화된 ELT 파이프라인.
  • Snowflake AI를 활용하는 완전한 지능형 고객 분석 플랫폼.
  • 역할과 정책을 갖춘 견고한 데이터 거버넌스 프레임워크.
  • 자체 데이터와 타사 데이터를 결합하여 보강한 분석용 뷰.
